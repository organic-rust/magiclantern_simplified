Raw preview (test)
==================

LiveView picture drawn by ML from the raw frame, in a display layer of
its own under ML's overlay (DIGIC 8, M6 Mark II 1.1.1).  Shows the whole
frame the sensor reads, e.g. 2x2 3:2, which Canon's LiveView crops to
its top 2000 rows.

Show: always, or toggled by each half-shutter press.  Size: 360x240
sampled and doubled (about 8 fps), or 720x480 (about 3 fps).
